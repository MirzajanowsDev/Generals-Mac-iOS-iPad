# 2026-10 Development Diary

## 2026-10-04 — Android hotspot LAN discovery

- Reviewed the existing local Android LAN changes against upstream #307 (carrier/virtual interface checks) and #313 (platform isolation).
- Wi-Fi/SoftAP enumeration excludes cellular and VPN interfaces, validates the real netmask and directed broadcast, and prefers the tethering bridge/AP over a station interface. SoftAP drivers without IFF_RUNNING remain supported; station and Ethernet interfaces require a carrier.
- Discovery uses a wildcard UDP receive bind on port 8086 and IP_PKTINFO for the selected LAN source/interface. Gameplay retains its ordinary socket bind.
- Added release logcat diagnostics for interface selection, bind, discovery destinations and received packets. Kept foreground WifiManager.MulticastLock acquisition/release and its manifest permissions.
- Closed remaining error paths: null IP enumeration in the LAN menu, truncated LAN messages, POSIX socket error mapping and bounded draining of discarded datagrams.
- Added policy regression tests and Linux socket tests for the actual IP_PKTINFO helpers. Added GitHub Actions native Release build, strict library staging, APK signing/verification and artifact upload.
- Three physical Android phones are unavailable in this session; the A/B/C hotspot acceptance test remains a device validation step.
